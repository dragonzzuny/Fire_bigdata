## 말하지 않는다

- 순찰이 화재를 몇 % 막는다 → **e로 두고 세 경우를 보여준다**
- 기획서 각 숫자가 왜 바뀌었는지 항목별 설명 → **재현할 수 없으므로 하지 않는다**
- "정확도가 높습니다" → **포착률·신뢰구간으로 말한다**

## 시연 영상 (리허설·백업용)

```bash
# 1) 대시보드를 먼저 띄운다
.venv/bin/python -m streamlit run app/streamlit_app.py --server.port 8601
# 2) 다른 창에서 녹화
.venv/bin/python scripts/18_demo_video.py            # 실제 시연 속도 (약 3분 50초)
.venv/bin/python scripts/18_demo_video.py --pace 0.4 # 흐름만 빠르게 확인
```

`outputs/demo_video/시연_불씨예보.mp4` 로 나온다. 쓰임은 둘이다.

- **리허설**: 영상을 틀어 놓고 대본을 얹어 읽는다. 어느 버튼이 몇 초 걸리는지
  몸에 익어야 발표장에서 침묵이 생기지 않는다. 계획서 생성에 약 25초가 걸리므로
  그 구간에 할 말을 미리 정해 둔다
- **백업**: 발표장에서 시연이 막히면 이 영상을 대신 튼다. 장표 6~11번보다 낫다

녹화되는 순서는 발표 시연 순서와 같다.
① 예방점검 배분 → ② 순찰 동선 → ③ 순찰 목적 변경(전후 비교) →
④ 계획서 생성 → ⑤ 대응취약 → ⑥ 업무 도우미
