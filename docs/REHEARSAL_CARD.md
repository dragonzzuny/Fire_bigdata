## 말하지 않는다

- 순찰이 화재를 몇 % 막는다 → **e로 두고 세 경우를 보여준다**
- 기획서 각 숫자가 왜 바뀌었는지 항목별 설명 → **재현할 수 없으므로 하지 않는다**
- "정확도가 높습니다" → **포착률·신뢰구간으로 말한다**
