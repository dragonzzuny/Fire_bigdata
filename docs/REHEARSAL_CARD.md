## 세 번은 반드시 말한다

1. "**예측은 수단이고, 결과물은 순찰 경로와 문서입니다**" (3장 · 15장 · 19장)
2. "**저희가 잰 것은 여기까지입니다**" (14장 · 18장)
3. "**같은 명령으로 다시 만들어집니다**" (12장 · 19장)

## 말하지 않는다

- 순찰이 화재를 몇 % 막는다 → **e로 두고 세 경우를 보여준다**
- 기획서 각 숫자가 왜 바뀌었는지 항목별 설명 → **재현할 수 없으므로 하지 않는다**
- "정확도가 높습니다" → **포착률·신뢰구간으로 말한다**
