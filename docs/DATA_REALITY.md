# 원본 데이터 실측 — 기획서 가정과 다른 점

2026-08-27, 소방안전 빅데이터 플랫폼에서 받은 실제 CSV 를 열어 확인한 내용.
**기획서를 쓸 때의 가정과 다른 것들이 있고, 이 문서가 그 차이의 목록이다.**
심사에서 물어볼 만한 것은 대부분 여기에 있다.

## 1. 컬럼은 한글이 아니라 영문 코드다

```
RCPT_DT              접수일시 (YYYYMMDDHHMMSS)
EMRG_RSCU_CTPV_NM    시도      EMRG_RSCU_GUGUN_NM  시군구
EMRG_RSCU_EMD_NM     읍면동    ROAD_NM             도로명
EMRG_RSCU_CLSF_NM    화재종별  EMRG_RSCU_KND_NM    재난종별
MUSES_NM             대상물 용도     TRGTOBJ_CLSF_NM  소방시설 설치대상 구분
TPBIZ_NM             다중이용업 업종  FRUSWTR_NM       소방용수시설 종류
FRUSWTR_LAT/LOT      소방용수시설 좌표
```

## 2. 주소가 한 컬럼이 아니라 조각으로 온다

시도·시군구·읍면동·리·도로명이 각각 별도 컬럼이다. 그래서 파이프라인은
조각을 조립해 정밀도별 키를 만든다 (`src/firebird/addresses.py`).

## 3. **도로명이 자주 비어 있다** — 가장 중요한 차이

| 데이터셋 | ROAD_NM 채움률 | EMD(읍면동) |
|---|---|---|
| 울산 화재발생 2005–2020 | **35%** | 100% |
| 울산 화재발생 2021 | 80% | 100% |
| 울산 특정소방대상물 | 94% | 100% |
| 울산 다중이용업소 | 100% | 100% |
| 울산 소방용수시설 | 88% | 99% |
| 세종 화재발생 | **32%** | 100% |
| 세종 소방용수시설 | **0%** | 98% |

기획서는 "(시군구·도로명)을 지오코딩"이라고 썼지만, **학습 라벨인 화재의 3분의 2에
도로명이 없다.** 그래서 지오코딩을 계층으로 만들었다:

```
1순위  시도 + 시군구 + 도로명    ← 500m 격자와 해상도가 맞는다
2순위  시도 + 시군구 + 읍면동    ← 항상 가능하지만 동 중심점이라 거칠다
3순위  시도 + 읍면동             ← 시군구가 없는 세종 단층제 대응
```

`manifest_<city>.json` 의 `coverage.*.by_level` 에 **어느 단계로 얻었는지**가 기록된다.
좌표 확보율만 말하고 그중 몇 %가 동 중심점인지 말하지 않으면 격자 해상도를
실제보다 좋게 주장하는 셈이 되기 때문이다.

## 4. `_0000` 과 `_2021` 은 같은 데이터의 두 벌이다

각 데이터셋이 `_0000`(누적)과 `_2021`(최신) 두 파일로 온다. 그런데 관계가 도시마다 다르다.

| | `_0000` | `_2021` | 처리 |
|---|---|---|---|
| 울산 화재 | 2005–2020 (27,995건) | **2021만** (3,039건) | 기간이 겹치지 않음 → 둘 다 사용 |
| 세종 화재 | 2012–2020 (2,835건) | 2012–2021 (2,804건) | **같은 사건이 양쪽에** → 하나만 사용 |
| 대상물·업소·용수 | 이전 스냅샷 | 최신 스냅샷 | `_2021` 만 사용 |

그냥 이어붙이면 세종 화재가 거의 두 배로 세어진다. **라벨이 두 배가 되면 그 뒤의
모든 수치가 무의미하다.** `dataset.select_fire_source_per_year()` 가 연도마다
'시각이 살아있는 비율'이 높은 파일을 고르고, 무엇을 버렸는지 manifest 에 남긴다.

## 5. `_2021` 파일은 시각(그리고 세종은 날짜까지) 이 뭉개져 있다

- `_2021` 파일의 `RCPT_DT` 는 **100% 가 `HHMMSS = 000000`** 이다.
- 세종 `_2021` 은 날짜도 월초로 밀려 있다 (`20120801000000`).

**결과: 시간대 분석(화면3)은 `_0000` 파일이 있는 2005–2020 구간에서만 가능하다.**
2021년 화재는 연간 라벨로는 쓰되 시간대 통계에서는 제외된다.
`manifest.fires.with_real_time` 에 그 건수가 남는다.

확인된 시간대 분포(울산 2005–2020, 실제 시각 보유분): 13–18시가 가장 많다 —
기획서의 "오후·심야" 주장과 부합한다.

## 6. **'특급/1급/2급' 안전관리등급 컬럼이 없다**

기획서는 대상물 등급 구성을 피처로 쓴다고 했으나, 원본의 `TRGTOBJ_CLSF_NM` 은
등급이 아니라 **소방시설 설치대상 구분**이다.

```
일반대상물 24,316 · 자동화재탐지설치대상 4,178 · 옥내소화전설치대상 2,245
스프링클러/물분무등설치대상 1,713 · 11층이상 268 · 연면적 15,000이상 205
```

그래서 등급 대신 **① 소방시설 설치대상 구분** 과 **② 용도(MUSES_NM, 32종)** 를
피처와 점검 규칙의 근거로 쓴다. 없는 컬럼을 있는 척 매핑하면 체크리스트가
현장과 어긋난다.

## 7. **세종 소방용수시설 좌표가 틀렸다**

`FRUSWTR_LAT/LOT` 가 세종(36.5N, 127.3E)이 아니라 **lat 35.5 / lon 128.5** —
경북 방향을 가리킨다. 조치원읍 소화전이 `35.52N, 128.61E` 로 찍혀 있다.
울산 좌표는 정확하다(성안동 `35.577N, 129.316E`).

대응: `configs/config.yaml` 의 도시별 `bbox` 로 원본 좌표를 검증하고, 경계 밖이면
버린 뒤 주소 지오코딩으로 대체한다. 버린 건수는 `manifest.source_coords` 에 남는다.
**좌표가 '있다'와 '맞다'는 다른 문제다.**

## 8. 세종은 시군구가 없다 (단층제)

`GUGUN_NM` 이 0% 채움. LOGO(구·군 제외) 검증의 그룹 키가 없으므로,
세종에서는 읍면동을 그룹으로 대신 쓴다.

## 9. 소방용수시설은 '소화전'만 분모로 삼는다

`FRUSWTR_NM` 에는 소화전(지상/지하) 외에 저수조·급수탑·관정·호스릴이 섞여 있다.
울산 3,359건 중 소화전은 3,212건. 저수조까지 세면 '소화전이 없는 격자'가
실제보다 적어 보인다.

## 10. 화재안전특별조사는 결합할 수 없다 (기획서 6.기타 확인)

울산 887,753행. 그런데 붙일 방법이 없다.

| 컬럼 | 채움률 | 비고 |
|---|---|---|
| `OJTFT_MNG_NO` 대상물 관리번호 | 100% (862,790개 고유) | **특정소방대상물 데이터셋에 이 번호가 없다** |
| `CHCK_DT` 점검일 | 96% | 2018-01-01 ~ 2021-12-16 |
| `SFTY_MNG_GRD_CD` 안전관리등급 | **0%** | 등급을 여기서도 못 얻는다 |
| `EVL2_CD` 평가결과 | **0%** | |
| 주소 | **없음** | 격자 배정 불가 |

`configs/schema.yaml` 에서 이 데이터셋의 `file_glob` 을 비워 기본 비활성화했다.
관리번호가 들어 있는 대상물 데이터를 확보하면 되살릴 수 있다.

## 이 차이가 기획서 수치에 미치는 영향

| 기획서 수치 | 영향 |
|---|---|
| 좌표 95.3% 확보 | 도로명만으로는 불가능(화재 35%). 읍면동 폴백 포함이면 달성 가능하나 **해상도가 다르다** |
| 상위 20% 포착 73% | 격자 배정이 동 중심점으로 뭉치면 포착률이 **높게** 나올 수 있다 (같은 동 화재가 한 격자에 모임) |
| 대상물 등급 구성 피처 | 등급 컬럼 없음 → 용도/설치대상 구분으로 대체 |
| 시간대(오후·심야) | 2005–2020 구간에서 확인 가능 |
| 소화전 없는 격자 48% | 소화전만 셀 때와 용수시설 전체를 셀 때가 다르다 |
| 점검 이력 연계 | 결합 키가 없어 불가 — 기획서 6.기타가 옳았다 |

읍면동 중심점 뭉침은 **포착률을 부풀리는 방향**으로 작용한다.
`manifest` 의 `by_level` 비율과 함께 읽지 않으면 성능을 과대평가하게 된다.

## 건축물대장 노후도 — 붙여 보고 안 써서 뺀 것

**가설**: 대상물·업소·소화전은 '언제부터 존재했는가'가 없어 2014년 행에도
현재 값이 들어간다(스냅샷 누수). 건축물대장에는 사용승인일이 있으니
`사용승인일 <= t` 인 건물만 세면 시계열이 되고, 스냅샷을 대체할 수 있다.

**한 일**: 울산 72개 법정동의 표제부를 전부 받아(약 13만 동) 읍면동 × 연도
노후도 피처 6종을 만들었다 — 동수, 연면적, 평균 경과연수, 30년 이상 비율,
5년 이내 비율, 동당 연면적. 값은 실제로 해마다 변한다(달동 노후비율
2014년 11.3% → 2021년 18.9%).

**결과**: 도움이 되지 않았다.

| 조건 | 없을 때 | 넣었을 때 | 차이 | 95% 신뢰구간 |
|---|---|---|---|---|
| 전체 모델 | 68.5% | 67.7% | −0.80%p | −2.53 ~ +0.98%p |
| 이력만(스냅샷 제외) | 68.1% | 67.6% | −0.51%p | −2.01 ~ +1.09%p |

두 경우 모두 신뢰구간이 0을 포함한다. **채택하지 않았다.**

**왜 안 됐다고 보는가**: 읍면동 단위라 같은 동의 격자가 모두 같은 값을 갖는다.
격자 사이를 가르지 못하니 격자 단위 화재 이력을 이길 수가 없다. 격자 단위로
붙이려면 건물마다 주소를 좌표로 바꿔야 하는데 울산 전체가 25만 동 규모라
무료 지오코딩 한도를 넘는다. 상세주소가 확보되면 다시 측정할 일이다.

재현: `scripts/15_fetch_buildings.py` → `scripts/16_eval_buildings.py`
기록: `outputs/building_feature_eval_ulsan.json`

건축물대장 자체는 버리지 않았다. **법정 서식([별지 제11호서식] 관리대장)의
연면적·건축면적·건축연도·건물동수**를 이 자료로 채운다 — 모델 피처로는
쓸모가 없어도 문서 작성에는 쓸모가 있다.

## 예방순찰의 법적 위치 — 법령에 '순찰'은 없다

이 저장소가 순찰 계획을 만들면서 확인한 것이다.

수집한 소방 법령 **457개 조문과 별표·서식 68건 어디에도 '순찰'이라는 말이
나오지 않는다.** (`lawdata.collect()` 결과를 직접 검색해 확인)

| 활동 | 법적 성격 | 근거 |
|---|---|---|
| 화재안전조사 | **법정 의무** | 화재예방법 제7조. 화재예방강화지구는 시행령 제20조 제1항이 **연 1회 이상**을 못박음 |
| 소방훈련·교육 | 법정(강화지구) | 시행령 제20조 제2항, 10일 전 통보(제3항) |
| **예방순찰** | **법정 의무 아님** | 소방기본법 제3조의 '화재 예방ㆍ경계' 업무를 관서가 자체 방식으로 수행 |

**이것이 이 서비스의 자리다.** 조사는 주기가 법으로 정해져 있지만, 순찰은
**방법과 횟수가 관서 재량**이라 지금은 경험과 관행으로 정해진다. 근거를 댈 자리가
비어 있다.

### 현장 실무 대조 (종로소방서 혹한기 기동순찰, 2026)

| 실무 | 이 서비스 |
|---|---|
| 센터별로 대상 개소를 나눔(대응단 10·신고 7·종로 11·연건 9·신영 8·숭인 14, 계 59개소) | 관서별 순찰 구역 배분 (`routing.plan_from_stations`) — **맞음** |
| 매일 2회 이상, 화재위험경보 해제 시까지 | 월 위험계수로 주차별 횟수 산출(12월 11회, 주당 2회) — **맞음** |
| 전열기구·전기가스·피난방화시설 확인 | 순찰 유형별 확인 항목 (`patrol_modes.checks`) — **맞음** |
| 대상이 **개소(건물)** 단위 | 500m **격자** 단위 — **다름** |
| 혹한기 등 취약시기 특별순찰 | `dry_season` 유형 + 월별 강도 — **맞음** |

다른 것은 **대상 단위**뿐이다(개소 vs 격자). 건물 식별키가 없어 생긴 한계이고
`docs/DATA_PROPOSAL.md` 의 제안 사유가 바로 이것이다.

횟수는 낸다. 다만 **관서 교대·인원 편성과는 잇지 못한다** — 몇 회가 필요한지는
계산하지만 그 회차를 누가 언제 나가는지까지는 근무편성 자료가 있어야 한다.

계획서의 법령 근거 절은 이 구분을 그대로 적는다 — 업무 근거(소방기본법 제3조)와
순찰 중 조치·조사 근거(화재예방법 제17조·제7조)를 나눠 쓴다. 조치 조문을
'순찰의 근거'로 달면 결재선에서 바로 걸린다.
